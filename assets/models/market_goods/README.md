# Рынок в 20 словах

20 самостоятельных статических GLB для будущего размещения на торговых рядах.
Набор не подключён к игре. Сервер, игровой клиент, персонажи и курица не изменены.

## Состав и формат

- Посуда (5): чайник, чайная чашка, миска, палочки, ложка.
- Продукты (10): чайные листья, варёный рис в тарелке, лапша в миске, баоцзы,
  яйцо, яблоко, банан, огурец, помидор, морковь.
- Бытовые вещи (5): бутылка, зонт, рюкзак, шляпа, пара туфель.
- Всего **4368 треугольника**, от 80 до 648 на модель, 1–4 материала на GLB.
- Плоские грани; без текстур, прозрачности, скелетов, анимаций и внешних ресурсов.
- glTF 2.0 Binary, метры, +Y вверх, +Z вперёд. Центр основания расположен в (0,0,0).
- Геометрия объединена по материалам: не более четырёх примитивов на предмет.

Чашка и миска имеют внутреннюю поверхность. Рис — приготовленный, с видимыми
зёрнами на низкой тарелке; лапша — жёлтые отдельные ленты в миске. Чай — сухие
листья в открытой упаковке. Вспомогательная посуда входит в бюджет соответствующего GLB.

## Генерация и запуск

Из папки `assets/models/market_goods`:

```bash
python3 generate.py
npm ci
npm run validate
npm run serve
```

Открыть http://localhost:8770/. Если сервер запускается из `assets/models`,
страница доступна по http://localhost:8768/market_goods/.
Генератор использует только стандартную библиотеку Python 3, без Blender,
ИИ, исходных моделей продавцов или сетевых запросов. Повторный запуск создаёт
байт-в-байт те же GLB и манифест.

JS-зависимости загружаются из локального `node_modules`, без CDN. Для русских
надписей и иероглифов используются системные шрифты; CJK-шрифт должен быть
установлен в ОС (например Microsoft YaHei или Noto Sans CJK).

## Просмотр

Выберите категорию и карточку. Модель открывается рядом с иероглифами,
пиньинем с тонами и переводом. Можно выбрать другой предмет из списка.
Камера автоматически подстраивается под габариты; это меняет только отображение,
метрический масштаб внутри GLB сохраняется.

Мышь/касание — вращение; колесо/жест двумя пальцами — масштаб. В области модели:
стрелки — поворот, +/− — масштаб, Home — сброс. Кнопки ракурсов: ¾, спереди,
сбоку, сверху. Карточки и кнопки доступны через Tab и Enter/Space.

## Каталог и будущая интеграция

`manifest.json` содержит версию формата, соглашения координат, категории и `models`.
Каждый элемент: `id`, `file`, `category`, `word_id`, `zh`, `py`, `ru`,
`dimensions_m`, `bounds_m`, `triangles`, `materials`, `bytes`, `sha256`.
Опциональный `note_ru` уточняет изучаемый продукт. Идентификаторы `word_teapot`,
`word_cup`, `word_bowl`, `word_chopsticks`, `word_tea`, `word_noodles` сохранены
из каталога игры. Остальные зарезервированы в этом наборе; серверный словарь
пока не расширяется.

```js
const gltf = await new GLTFLoader().loadAsync('/models/market_goods/teapot.glb');
scene.add(gltf.scene); // исходные метры; не применять нормализацию просмотрщика
```

Для многократного размещения позже переиспользуйте геометрию и материалы либо
InstancedMesh. Просмотрщик создаёт превью один раз и рисует выбранную модель
по изменению камеры; постоянного цикла анимации у набора нет.

## Проверка

`npm run validate` проверяет все GLB валидатором Khronos и загружает их через
Three.js: ошибки/предупреждения, бюджеты, материалы, внешние ресурсы, хеши,
основания, габариты, нормали и совместимость существующих `word_id`.

Для браузерной проверки сначала запустите HTTP-сервер и установите Chromium:

```bash
npx playwright install chromium
PREVIEW_URL=http://localhost:8770/ node browser_test.mjs
```

В PowerShell задайте `$env:PREVIEW_URL='http://localhost:8770/'`, затем выполните
`node browser_test.mjs`. Необязательные переменные: `CHROMIUM_PATH` (свой Chromium)
и `QA_OUTPUT` (папка снимков; по умолчанию временный каталог ОС).
Проверяются все 20 карточек, категории, ракурсы, мышь, клавиатура, сенсорное
вращение/масштаб, desktop 1280×960 и узкий экран 390×844, консоль и сеть.

## Языковые источники

Иероглифы и пиньинь всех 20 слов сверены 2026-11-01 с
[CC-CEDICT через MDBG](https://www.mdbg.net/chinese/dictionary?page=cedict).
CC-CEDICT распространяется под CC BY-SA 4.0; английская словарная база не включена
в этот архив. Русские подписи сформулированы для проекта.
Названия продуктов также сопоставлены с учебным материалом
[университета Тунцзи, Chinese Dishes](https://cdhk.tongji.edu.cn/_upload/article/files/cc/06/cd5446d74006a36b0e98ec552b3f/0ae245ea-31ce-4bde-accd-2808d96e6f0e.pdf).
«茶叶» означает чайные листья; «米饭» — приготовленный рис; «书包» — школьный
рюкзак/ранец. Подписи «Миска» и «Чайные листья» уточняют бытовое значение уже
существующих игровых слов, не меняя серверные данные.
