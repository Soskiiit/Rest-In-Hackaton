# Тележки уличной еды · GLB

Две оригинальные процедурные тележки на колёсах в духе уличных рынков Вьетнама и Таиланда
для «Шэньчжэньского экспресса». Геометрия, плоские нормали, цвета вершин и анимации
встроены в GLB. Внешних текстур, сжатия и обязательных glTF-расширений нет.

| Файл | Треугольники | Draw calls | Размер | Габариты X × Y × Z в покое |
|---|---:|---:|---:|---|
| [cart_banh_mi.glb](cart_banh_mi.glb) | 764 | 9 | 99 496 байт | 1,85 × 1,85 × 0,91 м |
| [cart_thai_noodle.glb](cart_thai_noodle.glb) | 932 | 12 | 125 040 байт | 2,49 × 2,72 × 1,94 м, включая зонт |

## Оптимизация

Модели рассчитаны на массовую расстановку в low-poly мире:

- лимиты генератора: не больше 1 000 треугольников и 16 draw calls на тележку;
- примитивы с 5–8 гранями, перекладины — прямоугольные бруски, колесо — восьмигранная шина и две спицы;
- цвет хранится в вершинах (`COLOR_0`), материалов всего три: `paint`, `glass` (прозрачный), `cloth` (двусторонний);
- неподвижные детали запечены в один меш на материал; отдельные меши только у подвижных узлов,
  поэтому все анимации работают как прежде.

**Бань-ми (Вьетнам):** крашеный бирюзовый шкаф с жёлтой полосой, стеклянная витрина с багетами
и начинками, вывеска на стойках с двумя красными фонариками, угольный гриль на боковой полке,
два велосипедных колеса, опоры и ручка.

**Лапша (Таиланд):** светлый стальной корпус с синей панелью, стеклянный ящик с лапшой, яйцами
и лаймами, котёл с бульоном на горелке, половники на рейлинге, газовый баллон под днищем,
полосатый зонт, два колеса и поворотное колёсико.

## Координаты и анимации

- Единица — метр; +Y вверх; сторона покупателя смотрит по +Z.
- Корневой узел — центр тележки на уровне земли (Y=0).
- Тележка катится вдоль X: ручка со стороны −X, при толкании едет к +X.
- Это иерархия жёстких частей с анимацией узлов, без скелета и skinning.

| Клип | Длительность | Что двигается |
|---|---|---|
| Idle | 4 с, цикл | Бань-ми: фонарики качаются. Лапша: зонт покачивается, половники раскачиваются |
| Roll | 2 с, цикл | Колёса делают один оборот (поворотное колёсико — четыре), фонарики/половники отклоняются и качаются, зонт сильнее покачивается |
| Open | 1,5 с, однократно | Бань-ми: задняя стеклянная створка витрины отъезжает, дверца шкафа открывается. Лапша: крышка котла поднимается, створка стеклянного ящика откидывается |

Open проигрывается один раз и удерживает конечную позу; закрытие — тот же клип с `timeScale = -1`.
Скорость Roll соответствует ≈ 1 м/с; для другой скорости меняйте `timeScale` пропорционально.

Анимируемые узлы: `L_Wheel`, `R_Wheel`, `Caster`, `L_Lantern`, `R_Lantern`, `Umbrella`,
`Ladle0…2`, `SlidingGlass`, `CabinetDoor`, `PotLid`, `BoxDoor`.

## Просмотр

Из этой директории:

```bash
npm ci
npm run serve
```

Открыть http://127.0.0.1:8766: выбор тележки, ракурса и клипа (Ожидание / Едет / Открыть).
HTML нельзя открывать через file://: GLTFLoader загружает файлы по HTTP.
Все JS-зависимости локальные после `npm ci`; CDN и интернет при просмотре не нужны.

## Использование в Three.js

Копии GLB лежат в `client/public/models/carts/` и доступны клиенту по пути `/models/carts/…`.
Создавайте отдельный AnimationMixer для каждого экземпляра.

```js
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const gltf = await new GLTFLoader().loadAsync('/models/carts/cart_thai_noodle.glb');
const cart = gltf.scene;
cart.position.set(104, 0, 118);
scene.add(cart);

const mixer = new THREE.AnimationMixer(cart);
const clip = name => mixer.clipAction(THREE.AnimationClip.findByName(gltf.animations, name));
const idle = clip('Idle'), roll = clip('Roll'), open = clip('Open');
idle.play();

open.setLoop(THREE.LoopOnce, 1);
open.clampWhenFinished = true;
function setOpen(isOpen) {
  open.paused = false;
  open.timeScale = isOpen ? 1 : -1;
  if (!open.isRunning()) open.reset().play();
  if (!isOpen) open.time = open.getClip().duration;
}
// Idle и Open можно проигрывать одновременно: они двигают разные узлы.
// Во время перемещения тележки: idle.stop(); roll.play(); в render-loop: mixer.update(deltaSeconds).
```

## Перегенерация и проверки

Генератор требует только Python 3, не использует Blender, сеть или случайные числа.
Повторный запуск создаёт идентичные байты GLB, обновляет `manifest.json`
и копирует GLB в `client/public/models/carts/`.

```bash
python3 generate.py
npm run validate
npm run previews
```

`npm run validate` проверяет оба файла Khronos glTF Validator и дополнительные условия:
GLB 2.0, внутренние ресурсы, нормали, лимиты треугольников/размера, имена и длительность клипов,
отсутствие двух каналов на один узел.

`npm run previews` поднимает временный HTTP-сервер на 127.0.0.1:8767, открывает установленный
Google Chrome через Playwright, проверяет загрузку, клипы, поворот колёс в Roll и движение
четырёх частей в Open, отсутствие ошибок консоли и неудачных запросов, затем сохраняет
изображения в `previews/`. Другой Chromium: `PLAYWRIGHT_CHROMIUM_EXECUTABLE=<путь>`.

Проверено: Chrome на macOS, 1280 × 1000. Оба GLB: 0 ошибок, 0 предупреждений валидатора.
Интеграция в игровой клиент и серверные изменения не выполнялись.
