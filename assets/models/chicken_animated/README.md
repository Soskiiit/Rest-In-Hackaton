# Анимированная курица

`chicken_animated.glb` — отдельный ассет на основе предоставленной модели **Chicken by jeremy - 1YE8U35HXsI.glb**. Исходник сохранён как `source.glb`, без изменения байтов. Автор исходной геометрии — jeremy; эта подготовка не меняет права на исходную модель. Условия использования исходного ассета сохраняются.

Модель не подключена к игре. Модели продавцов, игровой мир и сервер в рамках этой задачи не изменяются.

## Формат

- glTF 2.0 Binary, 656 788 байт, 3470 треугольников, 12 костей.
- Пять исходных материалов и два материала пиксельных очков, без текстур; внешних ресурсов для GLB не требуется.
- Единицы — метры, высота нейтральной модели около 0.60 м, +Y вверх, +Z вперёд.
- Начало координат на земле между лапами. Корневой узел не перемещается в анимациях.
- Добавлен скиннинг корпуса, шеи, головы, хвоста, крыльев, ног, стоп и пальцев. Белая сетка подразделена для сгибов, на боках добавлены тонкие подвижные поверхности крыльев с видимой нижней стороной. Нейтральный силуэт сохранён.

## Встроенные анимации

| Клип | Длительность | Режим | Поведение |
|---|---:|---|---|
| `Run` | 0.72 с | Цикл | Шаги на месте, корпус покачивается, голова двигается в такт |
| `Peck` | 2.4 с | Один раз | Наклоняет шею, три раза клюёт у земли, возвращается в нейтральную позу |
| `PanicRun` | 0.52 с | Цикл | Ускоренный бег, приподнятый корпус, вытянутая шея, частые взмахи двумя крыльями |

Чёрные ступенчатые очки с перемычкой и дужками целиком привязаны к голове. В опорной фазе лапа идёт к −Z относительно корпуса, в переносе — к +Z. В испуганном беге корпус слегка наклонён вперёд. Зелёная стрелка просмотрщика обозначает направление +Z.

Скорость и траекторию перемещения позднее задаёт игровой контроллер. `Run` и `PanicRun` — без root motion. `Peck` заканчивается нейтральной позой, отдельного `Idle` в файле нет.

## Генерация и проверка

Из этой папки:

```bash
python3 generate.py
npm ci
npm run validate
npm run serve
```

Генератор использует только стандартную библиотеку Python 3 и лежащий рядом `source.glb`. Он воспроизводимо создаёт `chicken_animated.glb` и `manifest.json`, содержащий SHA256 исходника.

Просмотрщик после `npm run serve` — `http://localhost:8769/`. Если HTTP-сервер запущен из `assets/models`, адрес — `http://localhost:8768/chicken_animated/`. Кнопки: бег, клевание, испуганный бег, пауза; доступны ракурсы ¾, сбоку, спереди и сзади. JS-зависимости локальные, CDN не используется.

Проверено валидатором Khronos: 0 ошибок / 0 предупреждений. В Three.js проверяются деформированная геометрия и положение лап/клюва относительно земли; беговые циклы замыкаются, клевание возвращается в нейтральную позу. В самом низком положении клюв находится примерно в 3 мм над поверхностью. Проверки не требуют моделей ИИ.

## Подключение позднее

```js
const gltf = await new GLTFLoader().loadAsync('/models/chicken_animated.glb');
scene.add(gltf.scene);
const mixer = new THREE.AnimationMixer(gltf.scene);
const actions = Object.fromEntries(gltf.animations.map(clip => [clip.name, mixer.clipAction(clip)]));
actions.Run.setLoop(THREE.LoopRepeat, Infinity).play();
// В цикле рендера:
mixer.update(deltaSeconds);
// Позицию и поворот задавать всей gltf.scene либо внешней группе.
```

Для `Peck`: остановить другие действия, вызвать `reset()`, задать `THREE.LoopOnce`, `clampWhenFinished = true`, затем `play()`. Переход к бегу выполнять явно через AnimationMixer. Для копирования скелетной курицы использовать `SkeletonUtils.clone`, а не обычный `Object3D.clone`.
