# Комичный турист

Отдельный будущий аватар игрока: светлая кожа, каштановые волосы, открытые глаза,
панама, бирюзовая рубашка, бежевые шорты, кроссовки, рюкзак и фотоаппарат.
В игру не интегрирован. Прежние модели и код игры не изменяются.

## Формат

- `comical_tourist.glb`: 1504 треугольника, около 0.48 МБ, 82 узла.
- Метры, +Y вверх, +Z вперёд, начало координат между ступнями на земле.
- Высота 2.03 м с панамой, глаза в нейтральной позе на высоте 1.70 м.
- Плоские грани, однотонные материалы; без текстур, пальцев и внешних ресурсов.
- Жёсткая подвижная иерархия, как у наших продавцов, без skinning.
- Панама — дочерний узел Head; рюкзак и камера — дочерние узлы Torso.
- Корневой узел неподвижен во всех клипах. Подъёмы и смещения внутри Jump/FallBack
  выполняются ActionPivot и заканчиваются на исходном месте.

## Анимации

| Клип | Длительность | Режим | Движение |
|---|---:|---|---|
| Idle | 3.2 с | Цикл | Спокойное покачивание корпуса и головы |
| Walk | 1 с | Цикл | Переваливающаяся ходьба на месте |
| Run | 0.65 с | Цикл | Быстрый бег на месте, наклон вперёд и работа рук |
| Wave | 2.2 с | Один раз | Приветствие рукой и весёлый наклон головы |
| Angry | 1.8 с | Один раз | Брови нахмурены, руки возмущённо движутся, нога притопывает |
| Jump | 1.2 с | Один раз | Приседание, прыжок, приземление и возврат в стойку |
| FallBack | 3.6 с | Один раз | Падение на спину с отскоком, подъём прыжком и стойка |

Опорная стопа в Walk/Run идёт в сторону −Z относительно корпуса, переносимая —
к +Z. Скорость и перемещение игрока задаст будущий контроллер игры. Для
однократных клипов используйте `LoopOnce` и `clampWhenFinished=true`.
В просмотрщике клипы переключаются с начала и сбросом предыдущего действия;
правила смешивания и прерывания падения определит будущая игровая интеграция.

## Генерация и просмотр

Из этой папки:

```bash
python3 generate.py
npm ci
npm run validate
npm run serve
```

Генератору нужны `generate.py`, `geometry.py` и только стандартная библиотека
Python 3. Он создаёт GLB и `manifest.json` воспроизводимо, без Blender,
нейросетей и доступа к сети. Все используемые геометрические функции находятся
в этом пакете; исходные генераторы продавцов не нужны.

После `npm run serve` открыть http://localhost:8771/. Если сервер запущен из
`assets/models`, адрес — http://localhost:8768/comical_tourist/.
Зависимости Three.js локальные, CDN не используется.

Кнопки выбирают клип, паузу и ракурс. Есть скорость 0.25–1.5×, вращение мышью
или касанием, масштаб колесом, автоматическое кадрирование полного движения.
Зелёная стрелка указывает +Z. В области модели стрелки поворачивают камеру,
+/− меняют масштаб, Home сбрасывает ракурс. Кнопки доступны через Tab и Enter.

## Проверки

`npm run validate` проверяет Khronos glTF Validator, все семь клипов и их
длительности, неподвижный корень, крайние позы, циклы, высоту стоп,
направление обеих стоп в опорной фазе, положение рук относительно головы,
одежды и аксессуаров. Допуск геометрии у земли — 1 мм; фактическая погрешность
интерполяции беговых ключей существенно меньше этого значения.

Для браузерной проверки сначала запустите HTTP-сервер:

```bash
npx playwright install chromium
PREVIEW_URL=http://localhost:8771/ node browser_test.mjs
```

В PowerShell: `$env:PREVIEW_URL='http://localhost:8771/'`, затем
`node browser_test.mjs`. Необязательные переменные: `CHROMIUM_PATH` и `QA_OUTPUT`.
По умолчанию снимки и кадры сохраняются во временной папке ОС.
Проверяются семь клипов, ракурсы, завершение падения, пауза, скорость, мышь,
масштаб, клавиатура, desktop 1200×1000 и узкий экран 390×844, консоль и сеть.

## Будущее подключение

```js
const gltf = await new GLTFLoader().loadAsync('/models/comical_tourist.glb');
scene.add(gltf.scene);
const mixer = new THREE.AnimationMixer(gltf.scene);
const actions = Object.fromEntries(gltf.animations.map(c => [c.name, mixer.clipAction(c)]));
actions.Idle.setLoop(THREE.LoopRepeat, Infinity).play();
// В игровом цикле: mixer.update(deltaSeconds).
```

Клонирование обычным `Object3D.clone(true)` подходит для этой жёсткой иерархии.
Каждому игроку нужен собственный AnimationMixer. Геометрия и материалы могут
переиспользоваться. Корневую позицию/поворот задаёт игровой код; размеры коллизии
и синхронизацию клипов потребуется согласовать отдельно при интеграции.
Манифест содержит SHA256 GLB, число треугольников и узлов, соглашения координат,
уровень глаз, длительности/режимы клипов и габариты полного движения для камеры.
