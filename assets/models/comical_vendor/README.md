# Комичный low-poly продавец

Отдельный оригинальный 3D-персонаж по предоставленному визуальному референсу: большая жёлтая коническая шляпа, красная куртка, крупная голова, длинные усы и короткие ноги. Это готовый ассет, без подключения к игровому клиенту или серверу. Существующие NPC не заменяются.

## Файл

`comical_vendor.glb` — самодостаточный glTF 2.0 Binary, 85 392 байта, 1180 треугольников, 51 узел, 8 однотонных PBR-материалов. Текстур, внешних файлов и обязательных расширений нет.

Единицы — метры; +Y вверх, +Z вперёд; начало координат между ступнями на земле. Высота в нейтральной позе около 1.72 м. Анимируются отдельные жёсткие части тела через иерархию узлов; skinning и внешняя анимационная библиотека не нужны. Это не Humanoid-скелет для автоматического ретаргетинга Mixamo.

## Встроенные клипы

| Клип | Длительность | Режим | Поведение |
|---|---:|---|---|
| `Idle` | 3.2 с | Цикл | Мягкое покачивание корпуса и головы |
| `Wave` | 2.2 с | Один раз | Широкий взмах рукой, наклон головы |
| `Angry` | 1.8 с | Один раз | Брови хмурятся, руки возмущённо двигаются, правой ногой притопывает |
| `Walk` | 1.0 с | Цикл | Переваливающаяся походка с противофазным движением рук и ног |

Начальные и конечные позы всех клипов совпадают с нейтральной. В `Walk` корневой узел неподвижен: последующее перемещение персонажа задаёт игровая логика.

## Повторная генерация

Генератор самостоятельный, использует только стандартную библиотеку Python 3. Не требует Blender, нейросетей, исходной картинки или старых моделей:

```bash
python3 generate.py
```

Он пересоздаёт GLB и `manifest.json` рядом с собой. Повторный запуск даёт идентичный бинарный файл.

## Просмотр и валидация

Из этой папки:

```bash
npm ci
npm run validate
npm run serve
```

Открыть `http://localhost:8768/`. Просмотрщик содержит четыре кнопки анимаций, паузу, скорость и ракурсы спереди / ¾ / сбоку / сзади. `Wave` и `Angry` автоматически возвращаются в `Idle`; переключение плавное. Все JS-зависимости загружаются локально из `node_modules`, CDN нет.

Если HTTP-сервер запущен из родительской папки `assets/models`, адрес просмотрщика — `http://localhost:8768/comical_vendor/`.

Проверено: Khronos glTF Validator — 0 ошибок / 0 предупреждений; загрузка в Three.js, все четыре клипа, совпадение конечных поз, переключение анимаций, возврат к ожиданию, пауза, desktop и мобильный экран.

## Подключение позднее (Three.js)

```js
const gltf = await new GLTFLoader().loadAsync('/models/comical_vendor.glb');
scene.add(gltf.scene);
const mixer = new THREE.AnimationMixer(gltf.scene);
const actions = Object.fromEntries(gltf.animations.map(clip => [clip.name, mixer.clipAction(clip)]));
actions.Idle.play();

// В render loop:
mixer.update(deltaSeconds);

// Пример: приветствие, затем переход обратно к ожиданию.
actions.Wave.reset().setLoop(THREE.LoopOnce, 1);
actions.Wave.clampWhenFinished = true;
actions.Wave.play();
actions.Idle.crossFadeTo(actions.Wave, 0.12, false);
mixer.addEventListener('finished', ({ action }) => {
  if (action === actions.Wave) {
    actions.Idle.reset().play();
    actions.Wave.crossFadeTo(actions.Idle, 0.12, false);
  }
});
```

Для ходьбы включать `Walk`, а позицию и поворот менять у `gltf.scene` либо у внешней обёртки. При удалении модели останавливать mixer и освобождать геометрию/материалы. Официальной интеграции этих примеров в приложение в данной задаче нет.

## Шесть новых вариантов

Исходный `comical_vendor.glb` сохранён без изменений. Новые модели самостоятельны: каждая содержит собственные материалы, геометрию и четыре анимационных клипа с теми же именами и длительностями.

| Файл | Образ | Треугольники |
|---|---|---:|
| `vendor_green.glb` | Зелёная куртка, короткая причёска, без усов | 1108 |
| `vendor_blue.glb` | Синяя куртка, пучок, выше и стройнее, без усов | 1108 |
| `vendor_yellow.glb` | Горчичная куртка, чёлка, низкий и округлый, без усов | 1108 |
| `vendor_vest.glb` | Бордовый жилет поверх светлой рубашки, седина, широкие брюки, без усов | 1156 |
| `vendor_curly.glb` | Бирюзовая куртка, животик, зачёсанные волосы, усы загнуты вверх | 1196 |
| `vendor_orange.glb` | Оранжевая куртка, широкие плечи, шляпа, усы вниз и бородка | 1180 |

Генерация всей новой коллекции:

```bash
python3 generate.py --variants
```

Настройки находятся в `VARIANTS` внутри генератора: палитра `colors`, причёска `hair`, цвет волос `hair_color`, шляпа `hat`, усы `mustache` (`none` / `up` / `down`), бородка `goatee`, жилет `vest`, широкие брюки `wide_pants`, общий масштаб `scale`, ширина/глубина корпуса `width` / `depth`. Значение `red` в палитре задаёт основной цвет одежды независимо от его фактического оттенка.

`variants.json` — общий манифест; `vendor_*.json` — индивидуальные параметры моделей. Различия в пропорциях встроены в GLB; при импорте не сбрасывать масштаб корневого узла. Ходьба остаётся на месте. Пустой анимируемый `MustachePivot` у безусых вариантов оставлен для общего анимационного контракта.

В просмотрщике «Вся коллекция» показывает шесть новых персонажей; исходный красный выбирается отдельно. Во всех режимах доступны анимации и ракурсы. `npm run validate` проверяет все семь GLB. В игру, клиентские ассеты и серверный каталог новые модели не подключены.
